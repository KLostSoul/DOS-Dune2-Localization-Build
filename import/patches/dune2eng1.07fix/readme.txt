Пакет обновлений от MrFlibble 
для английской версии игры
Dune II: The Building of a Dynasty v1.07.

===============================================================================

Установка обновлений

1. Папка V107UPG включает обновление игры для гибкой настройки аудио устройств
и исправления ошибок игры. Для установки скопировать все файлы из папки DYNASTY 
в каталог с игрой, перезаписывая существующие. Подробности читайте в файле 
dune2fix.txt, в папке обновления.

2. Не обязательное дополнение в папке SFX-FIX включает исправленный пакет файлов
речевых оповещений в игре. В том числе устраняет ошибки со звуком при запуске 
игры под ОС Windows. Совместим с Super Dune II. Скопировать файлы в папку с игрой, 
перезаписывая существующие.

3. Папка GUS-FIX содержит факультативный патч, добавляющий поддержку аудиокарты
Gravis Ultrasound. Совместим с большинством версией игры для запуска в DOSBox
с установленным пакетом драйверов Gravis Ultrasound. Для установки скопировать 
файлы в папку с игрой, перезаписывая существующие (папка SETUP_EU не нужна).
Для воспроизведения музыки аудиоустройством указывать UltraSound (MIDI). 
Режимы MT-32/SoundCanvas работают некорректно. Запуск игры через DUNE2G.BAT.

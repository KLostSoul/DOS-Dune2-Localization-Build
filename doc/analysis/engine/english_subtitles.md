# 영어 자막과 음성의 출력 분기

영어 모드는 음성 피드백 표를 거쳐 자막을 출력한다. 피드백 항목의 문자열 ID가 0이면 원본 분기가 자막 조회·그리기를 건너뛰므로 비영어와 표시 결과가 달라진다.

## 원본 코드 흐름

아래 주소는 실제 FBOV 모듈의 상대 주소다. 오버레이 명령에 저장된 FAR 세그먼트 피연산자는 FBOV 디렉터리 선택값일 수 있으므로 실제 대상 모듈로 변환해 읽는다.

- 이벤트 함수 `32F0:07B6`은 문자열 그리기 `32F0:0BF4`를 사용한다.
- 언어 인덱스 `DS:[37AA]`의 0은 영어다. 데이터 세그먼트의 이미지 상대값은 `3342h`다.
- `32F0:093F`의 `75 44`는 비영어를 `0985`의 일반 문자열 경로로 보낸다.
- 영어는 `32F0:094C`에서 음성 피드백 게이트 `3286:002A`를 호출한다. 원시 명령 `9A 2A 00 80 05`의 `0580h`는 FBOV 선택값이며, 디렉터리에서 `3286h`로 대응한다.
- 피드백 항목 `[인덱스×0Eh+031Ch]`가 0이면 `32F0:0961`의 `74 20`이 `0983`으로 이동해 자막을 생략한다.
- 표시 경로는 `32F0:0973`에서 원래 이벤트의 문자열을 `0DD4:005F`로 조회하고 `097D`에서 `32F0:0BF4`로 전달한다. 조회 CALL의 원시 세그먼트 피연산자 `0078h`도 FBOV 선택값이다.

## 패치

`32F0:0961`의 `74 20`을 `90 90`으로 바꾼다. 언어 분기 `093F`와 음성 피드백 호출 `094C`는 보존한다. 음성 조회를 건너뛰지 않으면서 원래 이벤트 문자열 ID로 자막을 출력한다.

원본 EXE에서 이 분기의 파일 위치는 `0x516F1`이다. 파일 위치는 이미지 상대 세그먼트나 실행 중 CS:IP와 구분한다. 변경은 2바이트이며 실행 파일 크기·상주 메모리·오버레이 표를 늘리지 않는다.

## 검사 범위

원본과 최종 EXE의 대상 FBOV 모듈에서 생략 분기의 변경과 원래 언어·음성·문자열 출력 경로 보존을 대조한다. 음성 피드백 게이트의 내부 전체 동작을 이 모듈만으로 판정하지 않으며 원래 호출 규약을 유지한다. 한글 토큰의 전처리는 [유니폰트 자막](../fonts/unifont_cinematics.md)을 따른다.

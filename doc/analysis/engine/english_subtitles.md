# 영어 자막과 음성의 출력 분기

영어 모드는 음성 피드백 표를 거쳐 자막을 출력한다. 피드백 항목의 문자열 ID가 0이면 원본 분기가 자막 조회·그리기를 건너뛰므로 비영어와 표시 결과가 달라진다.

## 원본 코드 흐름

- 이벤트 함수 `3208:6B37`은 문자열 그리기 `3208:6F75`를 사용한다.
- 언어 인덱스 `4342:37AA`의 0은 영어다.
- `3208:6CC0`의 `75 44`는 비영어를 `6D06`의 일반 문자열 경로로 보낸다.
- 영어는 `3208:6CCD`에서 `0580:002A`를 호출한다. 명령 바이트는 `9A 2A 00 80 05`다.
- 피드백 항목 `[인덱스×0Eh+031Ch]`가 0이면 `3208:6CE2`의 `74 20`이 `6D04`로 이동해 자막을 생략한다.
- 유효 항목은 `0000:07DF`로 문자열을 조회하고 `3208:6F75`로 표시한다.

## 패치

`3208:6CE2`의 `74 20`을 `90 90`으로 바꾼다. 언어 분기 `6CC0`과 피드백 호출 `6CCD`는 보존한다. 음성 조회를 건너뛰지 않으면서 원래 이벤트 문자열 ID로 자막을 출력하는 방식이다.

해당 분기는 2바이트이며 실행 파일 크기·상주 메모리·오버레이 표를 늘리지 않는다. 함수 주소는 분석 대상의 논리 주소다. 실제 파일 위치는 빌더가 모듈과 명령 서명으로 확인한다.

## 검사 범위

검사는 생략 분기 변경, 원래 피드백 호출과 공통 출력 경로 보존을 대조한다. `0580:002A`의 내부 전체 동작은 `3208` 오버레이만으로 판정할 수 없으므로 호출 규약을 유지한다. 한글 토큰의 전처리는 [유니폰트 자막](../fonts/unifont_cinematics.md)을 따른다.

# 원본 출력기와 한글 토큰 처리의 인터페이스

## 원본 함수의 입력과 출력

원본 주소는 이미지 상대 세그먼트:오프셋이다. REA 기본 선형 주소에는 분석 적재 기준 10000h가 더해진다. 오버레이의 실제 페이로드 주소와 상주 게이트 주소는 구분한다.

| 단계 | 원본 계약 | 한글 처리의 연결 |
|---|---|---|
| 리소스 읽기 `0DD4:0088` | 저장 위치에서 문자열 데이터를 읽음 | 파일·청크·길이 규약을 유지하고 번역 리소스를 생성 |
| 쌍 압축 해제 `2307:00F4` | 상위 비트가 설정된 바이트를 내장 두 글자 표로 전개 | 원본 해제기를 유지 |
| 확장 바이트 해제 `2307:0002` | ESC 뒤 바이트에 7Fh를 더함 | 2바이트 토큰을 기존 ESC 저장 규칙으로 인코딩 |
| 일반 줄바꿈 `0EED:01B8` | 정방향 폭 합산과 역방향 공백 탐색 | 각 순회가 문자 경계로 자기 포인터를 갱신 |
| 설명문 분할 `32DD:1893` | 폭·공백·문장부호·CR·NUL에 따라 버퍼를 분할 | 원래 분할 순서를 유지하고 토큰 소비 길이를 반영 |
| 한 글자 폭 `2326:0009` | 스택의 문자 인자로 폭과 간격을 반환 | 문자열 소유자의 포인터를 임의로 변경하지 않음 |
| 서식 처리 `0000:111F` 이후 | `%s`·`%d` 등 가변 인자를 바이트 문자열로 전개 | 원본 ASCII 서식과 인자 규약을 유지 |
| 문자 루프 `29C7:0004` | 좌표·경계·개행·글리프 호출과 다음 문자 이동 | 유효 토큰의 두 바이트를 한 글자로 소비 |
| 픽셀 출력 `20AA:07BD` | 활성 FNT의 표와 색 변환을 사용 | 한 슬롯 작업 FNT로 글리프를 전달한 뒤 드라이버 캐시 복원 |
| 페이지 선택 `20AA:0E02` | 활성 화면 번호로 작업 페이지를 선택 | 원본 드라이버의 페이지 선택 유지 |

폭 조회와 문자열 순회는 별개다. 문자열 포인터가 없는 콜백에서 다음 바이트를 읽거나 부모 스택 프레임의 포인터를 바꾸면 정방향·역방향 호출 계약이 깨진다. 현재 구현은 판독기가 문자·소비 길이를 반환하고 각 순회 함수가 자신의 위치를 갱신한다. 구체적인 연결은 [원본 출력 인터페이스](native_output_rebuild.md#한글-토큰과-원본-인터페이스)와 [폭 콜백 계약](../fonts/dalmoori_width_contract.md)을 따른다.

## 리소스와 서식 바이트

멘타트는 문자열 바이트뿐 아니라 NAME·DESC·INFO의 청크 길이·패딩·본문 오프셋을 함께 갱신해야 한다. 문자열 인코딩의 왕복 일치만으로 원본 탐색기가 다음 청크를 읽는다고 보장할 수 없다. [INFO 길이](mentat_info_length.md)와 원본 IFF 계약을 함께 검사한다.

현행 한글·비ASCII 부호 토큰의 두 바이트는 ASCII 범위 밖에 있다. `%`·공백·문장부호·NUL과 구분하면서 원래 `%s`·`%d`와 단축키의 ASCII 바이트를 유지한다. 토큰 범위·문자표·글리프 선택은 [폰트 규약](../../FONTS.md)을 따른다.

## 오버레이 분석의 주소 규칙

설명문 모듈은 MZ 적재 이미지 뒤의 FBOV 오버레이다. 원본 모듈 195의 코드 크기는 `1A7Ch`이며 문장 분할 진입은 `32DD:1893`이다. REA 분석에서는 추출한 모듈에 분석용 MZ 헤더를 붙여 열었다. 분석용 선형 `11893h`가 이 진입에 대응한다.

분석 컨테이너의 외부 FAR 호출은 원래 FBOV 선택값을 갖는다. 자동 외부 호출 이름을 게임의 실제 호출 대상으로 간주하지 않고 게이트·재배치·실제 명령 바이트를 대조한다. Ghidra의 세그먼트 MOV 피연산자 방향과 자동 함수 경계도 원본 바이트와 교차 확인한다.

## 검사 범위

`python tools/check_final_build.py --only hangul latin unifont subtitles`는 생성 토큰·글리프·폭·서식과 자막 전처리를 대조한다. 제한 명령 실행은 DOS·장치·전체 플레이 상태를 직접 관측하는 검사와 구분한다.

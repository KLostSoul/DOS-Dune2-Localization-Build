# 실행 파일·문자열·CG의 리소스 구조

게임 자료는 DOS MZ 실행 파일, FBOV 오버레이와 PAK 컨테이너로 나뉜다. 한글화 대상도 문자열표, 멘타트 레코드, 지도 INI, 실행 파일 내장 문구와 그림 속 글자로 구분해야 한다.

## 파일과 번역 대상

| 자료 | 내용 |
|---|---|
| DUNE2.EXE | 시작 코드·게임 함수·오버레이·내장 이름과 진단 문구 |
| DUNE.PAK | 공통 게임 자료와 원본 FNT |
| ENGLISH.PAK | DUNE.ENG·INTRO.ENG·멘타트·크레딧과 언어별 UI 그림 |
| SCENARIO.PAK | 시나리오와 REGION INI의 임무 지도 문구 |

원문 추출은 총 1,350행이다. 문자열표 945행, 멘타트 286행, 크레딧 76행과 지도 INI 43행을 포함한다. 원문은 `export/strings/`, 번역 입력은 `import/strings/`에 둔다. 실행 파일 문자열 후보는 파일 오프셋으로 기록하며 실제 표시 여부와 리소스 식별자 여부를 구분한다.

## 문자열 해제와 출력

문자열표와 멘타트는 저장 형식에 따라 쌍 압축·ESC 고위 바이트 해제를 사용한다. 멘타트의 NAME·DESC·INFO는 본문 오프셋·길이와 연결되므로 문자열만 바꿀 수 없다. 서식 처리·폭 계산·줄바꿈·픽셀 출력은 원본 엔진의 계약을 유지한다.

기본 폰트는 NEW8P, 작은 메뉴 보조 폰트는 NEW6P, 영상은 INTRO.FNT를 사용한다. 실제 활성 폰트와 문맥별 선택은 [FNT 엔진](font_engine.md)과 [화면별 관측](font_runtime_debug.md)에 설명한다. 한글 토큰과 현재 메모리 배치는 [폰트 안내](../../FONTS.md)를 따른다.

## 그림 속 글자

가문 가입 질문은 MISC.ENG CPS의 그림 복사다. MENTAT·OPTIONS·생산 버튼 등도 언어 UI 그림에 포함될 수 있다. 이런 글자는 문자열 CSV나 FNT 교체만으로 바뀌지 않는다. [질문 원본](../graphics/house_question_source.md)과 [CG 코덱](../graphics/graphics_codec.md)을 따른다.

## 분석 주소

MZ 파일 오프셋, 로드 모듈의 논리 세그먼트, FBOV 스텁과 실제 페이로드 주소는 구분한다. 자동 디스어셈블러가 초기 적재 영역만 읽는 경우 오버레이를 별도로 해제하고 게이트의 대상 오프셋과 재배치를 대조해야 한다.

# CG 코덱과 가문 질문의 검수 범위

CG 검수는 화면 RGB뿐 아니라 팔레트 색 번호, 투명색, 리소스 형식과 PAK 멤버 보존을 확인한다. 편집 범위는 [CG 안내](../../GRAPHICS.md#선택한-편집-범위)를 따른다.

## 코덱 왕복

원본 리소스에서 해제한 픽셀을 인코딩한 뒤 다시 해제해 프레임 수·크기·픽셀·팔레트·투명색을 비교한다. 편집 PNG도 같은 제약으로 검사하고, 수정 리소스만 PAK에 교체됐는지 대조한다. 색이 같더라도 번호가 다르면 동일한 입력으로 취급하지 않는다.

## 버튼과 가문 질문

BTTN.ENG와 SCREEN.CPS는 각 화면의 별도 버튼 그림이다. 한쪽 편집이 다른 쪽에 자동 복사되지 않는다. MISC.ENG의 질문은 폰트 문자열이 아니라 그림 복사이며, 영어 완성 문장 세 행과 게임 ID의 대응을 검사한다.

ENG/FRE/GER×세 가문의 9조합에서 원본·대상 좌표, 폭·높이, 페이지 인자와 SP·SI를 검사한다. 영어는 완성 문장 한 행, 비영어는 원래 공통 앞부분과 가문명 두 조각을 사용해야 한다.

## 메모리와 실행 범위

가문 질문 패치는 원래 두 FAR 복사 호출과 인자 규약을 유지하고 별도 상주·DOS·XMS 할당을 추가하지 않는다. 정적·제한 명령 검사는 실제 게임의 세 언어 화면을 모두 관찰한 결과와 구분한다.

원본 복사 함수와 단위는 [질문 원본](../graphics/house_question_source.md), 행 계산은 [가문 행 선택](../graphics/house_question_row_order.md), 팔레트와 투명색은 [HERALD](../graphics/herald_palette_repair.md)·[MENTAT](../graphics/mentat_transparency_repair.md)에 설명한다.

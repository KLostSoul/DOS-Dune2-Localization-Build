# 최종 빌드의 검수 범위

최종 빌드 검사는 입력 자료, 생성 코드, 메모리 배치와 CD 배포물을 대조한다. 실행 중 게임 화면 전체를 대신하는 검사는 아니며 제한 명령 실행의 서비스 모형과 실제 DOS 환경을 구분한다.

## 실행 명령과 보고서

```powershell
python tools/check_final_build.py
```

보고서는 `build/final-build-check.json`에 생성된다. `--only`로 영역을 선택하고 `--list`로 목록을 확인한다. 상세 항목은 [도구 안내](../../../tools/README.md#최종-빌드-검사)를 따른다.

## 검사 영역

| 영역 | 판정 대상 |
|---|---|
| 패키지 | 원본 CD 해시, BIN 파일·EDC/ECC, CUE, Xdelta 복원 결과 |
| 구조 | MZ 이미지 끝·재배치·스택·FBOV 변경 범위·HitSquad Fix |
| 글꼴 | 토큰·문자표·폭·픽셀·캐시 복원·XMS 적재와 실패 정리 |
| 문자열 | REGION INI의 고위 바이트, 가문 표시 이름, 서식·단축키 |
| 화면 스타일 | 원본 가장자리 클래스와 색, 정보창의 지역 줄 간격 |
| 치트 | 입력 소유권·명령 효과·생산 가속·지도 공개 |
| 영상 | 자막 전처리·두 가문의 마지막 자막과 입 애니메이션 |

## 실행 확인과의 경계

Unicorn 검사는 DOS·XMS·원본 외부 호출을 제한된 서비스 모형으로 처리한다. 분기·스택·레지스터·데이터 보존은 이 범위에서 검사하며 장시간 플레이·실제 사운드·마우스 커서·모든 미션 상태를 실행했다고 해석하지 않는다.

검사 전후에 번역 입력과 최종 게임·배포물 해시를 비교해 변경되지 않았는지 확인한다. 생성 시점의 기능·수량·해시는 [최종 빌드 상태](../../STATUS.md)를 따른다.

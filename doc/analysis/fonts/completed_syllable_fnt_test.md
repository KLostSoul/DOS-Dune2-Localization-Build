# 조합 글리프와 완성 음절의 대조 방법

조합형 FNT의 검사는 입력 선택표, 합성 결과와 출력 셀을 분리한다. 비트맵 일치는 게임 화면에서의 가독성이나 줄 배치까지 보증하지 않는다.

## 전체 음절 비교

U+AC00..U+D7A3의 11,172개 음절을 L/V/T로 분해해 조합하고, 독립적으로 읽은 선택표와 16×16 완성 음절 비트맵에 대조한다. 분석 표본에서는 조합·기준 비트맵 불일치가 각각 0개였다.

## 15×15 저장과 16×16 출력

구성 글리프의 빈 첫 행·첫 열을 생략해 15×15로 저장하고 `(1,1)`에 그리면 원래 16×16 셀을 복원할 수 있다. 이 경로도 11,172개 전체 음절에 대해 원래 16×16 결과와 대조한다.

## 10×10 변환의 한계

316개 구성 글리프를 10×10으로 줄인 FNT는 7,874바이트다. 16×16 기준과 다른 해상도이므로 원본 조합 일치 결과를 축소 글꼴의 품질 판정으로 사용할 수 없다. 셀 폭·메뉴 높이·줄 간격·선택 영역은 별도로 검사한다.

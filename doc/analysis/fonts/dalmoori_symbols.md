# 달무리 부호를 한글 음절 FNT에 추가 — 2026-10-22

사용자가 제공한 `G:/Codex/Hangul/font/dalmoori-font/dalmoori.ttf`에서 기본 ASCII 부호 32개와 가운뎃점 `·` 1개를 추출해 기존 한글 음절 FNT 뒤에 추가했다. 영문·숫자는 기존 게임 FNT를 계속 사용한다.

## 원본과 추출

- TTF SHA-256: `ba40b8f9ada002005d1f5f3676a82b7bff07ddbd186a923073101099131999e6`.
- TTF em은 64이며 글리프 꼭짓점은 8단위 픽셀 격자 위에 있다. 곡선 없이 직선 윤곽으로 구성된 부호를 픽셀 중심의 nonzero winding 규칙으로 채웠다. FreeType 힌팅·보간·안티앨리어싱·축소를 사용하지 않았다.
- 부호는 원래 전진 폭 4픽셀, 높이 8픽셀 셀을 사용한다. 기존 한글과 같은 기준선에 맞춰 `,`와 `_`의 아래쪽 픽셀도 보존했다.
- 현재 한글 HEX와 TTF의 일부 음절은 획이 다르므로 TTF로 한글을 다시 만들지 않았다. 기존 639개 음절의 레코드와 비트맵은 바이트 단위로 보존했다. 참고 대조 결과는 추출 manifest에 기록했다.
- 추출 자료: `font/dalmoori-symbols/dalmoori-symbols.hex`, `manifest.json`, `symbols.png`, `samples.png`.

## 추가 FNT와 출력

- 글리프 수: 기존 한글 639 + 부호 33 = **672개**.
- 추가 FNT: `font/dalmoori-symbols/DUNEHAN-672.FNT`, 6,744바이트.
- 게임 파일: 새 빌드의 `source/VIRGIN/DUNE2/DUNEHAN.FNT`와 같은 바이트다.
- 기존 음절 0..638 뒤에 부호 639..671을 추가했다. 현재 한글 토큰 해석과 639개 음절의 인덱스는 바꾸지 않았다.
- `ReadGlyph`의 1바이트·2바이트 소비 계약은 그대로다. 폭 계산과 글리프 그리기 단계에서만 원본 ASCII 부호를 추가된 레코드로 연결한다. 가운뎃점은 CP437 `FA`를 사용한다. 새 문자 압축표나 문자열 인코딩은 도입하지 않았다.
- 부호 폭은 원래 폭 4 + 좌우 여백 각 1 = 6픽셀이며, 여기에 기존 출력 스타일의 문자 간격을 더한다. 간격 -1인 문자열에서는 전진 폭이 5픽셀이다.
- 메뉴에는 부호 테두리를 추가하지 않는다. 설명용 스타일 `0x30`에서는 한글과 같은 테두리를 적용한다. 기존 설명문 줄 피치 11, 그림 내부 짧은 설명 줄 피치 11, 게임 메뉴 버튼 텍스트 Y+1은 유지했다.

## 빌드와 메모리

- 기준: `build/dalmuri639-menu-text-y1`.
- 기준 EXE SHA-256: `04099859d3ab7eafa5b5a528b7c851e452ebf5c7a242cb2c35171c857091064d`.
- 수정본: `build/dalmuri672-symbols`.
- 수정 EXE SHA-256: `3493f548bb1d8b0f3f201f08186bb95a86b341c9540f64a5cbb45a2e9f95e88b`.
- 확장 모듈: 7,568 → 8,144바이트. **상주 이미지 증가 576바이트**.
- 별도 DOS 폰트 블록·FAR 힙 할당·XMS 추가 요청은 없다.
- 치트 모듈을 `3EDB → 3EFF`, 스택 기준을 `3F74 → 3F98`로 이동했다. 기존 검증된 치트 소스를 이전 주소로 조립해 기준 바이트와 일치함을 확인한 후, 새 주소로 다시 조립했다. 치트를 가리키는 기존 MZ 재배치 위치 다섯 곳의 세그먼트 값을 갱신했다.
- 새 스택 기준은 새 MZ 로드 이미지 끝 `44580`과 일치한다. 오버레이 전체는 기준 빌드와 바이트 단위로 동일하며, 새 MZ 끝 뒤로 이동한 위치만 달라졌다.
- 기준 폴더와 저장 데이터는 보존하고 새 빌드로 복사했다. 원본 FNT·PAK 리소스도 바꾸지 않았다.

## 확인 범위

`tools/verify_dalmoori_symbols.py`가 원본 픽셀 출력 명령을 제한 CPU에서 실행했다.

- 기존 한글 639개 전체: 원본 NEW6P·NEW8P 환경과 메뉴·설명 두 스타일에서 기준 빌드와 픽셀 및 호출 좌표 일치.
- 영문 대소문자·숫자: 기존 출력 픽셀 일치.
- 부호 33개 전체: 추출된 원본 비트맵과 실제 렌더러 출력 픽셀 일치. 설명 스타일의 테두리도 주변 1픽셀 기준과 일치.
- 부호 폭: 기존 스타일 간격 -2/-1/0을 합산한 전진 폭 일치.
- 한글·부호·영문 혼합 고정 간격 출력: 1바이트 부호와 2바이트 음절을 각각 한 글자로 소비하고 중복 출력하지 않음.
- 매 글리프 뒤 원본 드라이버 FNT 캐시 복원 확인.
- 보고서: 수정본의 `symbols-build-report.json`, `symbols-static-check.json`.

DOSBox-X와 게임을 실행하지 않았다. 실제 게임 화면 확인은 사용자 확인 전이다. 루트 `듄2_한글테스트.bat`은 이 수정본을 실행한다.

재현 도구는 `tools/extract_dalmoori_symbols.py`와 `tools/build_dalmoori_symbols_runtime.py`이며, 검사를 통과한 후 실행 배치를 연결한다.

# 달무리 부호의 래스터화와 FNT 레코드

달무리 부호는 원본 TTF의 픽셀 격자를 보존해 8픽셀 높이 비트맵으로 변환한다. 게임 문자열의 ASCII 바이트와 표시 글리프를 분리하므로 `%s`·`%d`·단축키 판독을 유지할 수 있다.

## TTF의 픽셀 격자

분석 TTF의 SHA-256은 `ba40b8f9ada002005d1f5f3676a82b7bff07ddbd186a923073101099131999e6`이다. em은 64이고 꼭짓점은 8단위 격자에 놓인다. 직선 윤곽을 픽셀 중심 nonzero winding 규칙으로 채워 힌팅·보간·안티앨리어싱에 따른 획 변형을 피한다.

기본 ASCII 부호 32개와 가운뎃점의 고정 슬롯은 639~671이다. 기본 전진 폭 4픽셀에 좌우 1픽셀 여백을 더해 셀 폭 6을 사용한다. 원본 스타일 간격 -1을 적용하면 실제 전진 폭은 5다. 쉼표와 밑줄의 아래쪽 픽셀도 같은 기준선에 맞춘다.

## 문자열과 레코드

ASCII는 1바이트로 유지한다. 폭 조회와 픽셀 출력 단계에서 달무리 FNT 레코드를 선택한다. 1·2바이트 소비 계약과 NUL 종료를 바꾸지 않는다. 한글·알파벳·숫자·부호의 공용 입력은 `font/composed-hangul.hex`다.

비ASCII 부호의 토큰과 문자열별 선택은 [달무리 영문·부호](dalmoori_latin_symbols.md), 테두리는 원본 스타일을 따르는 [가장자리 규칙](../ui/font_edges.md)에 설명한다. FNT 크기가 바뀌면 빌더가 뒤쪽 치트·스택·재배치 위치도 다시 계산한다.

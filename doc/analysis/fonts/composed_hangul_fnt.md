# 조합형 한글 FNT의 데이터와 토큰 계약

조합형 비교 구현은 초성·중성·종성 구성 글리프와 선택표로 완성 음절을 그린다. 최종 빌드의 완성 음절 FNT와 구분되는 출력 방식이다.

## D2HFNT1 구조

10×10 조합 FNT는 24바이트 헤더, 초성 배치 선택 42바이트, 조합 인덱스 선택표 1,488바이트와 316개 1bpp 구성 글리프로 이루어진다. 파일 크기는 7,874바이트다.

## 비교 구현의 토큰

완성 음절 인덱스 `n=0..11171`에 대해 `lead=80h+floor(n/127)`, `trail=1+(n mod 127)`을 저장한다. 후행 바이트를 0으로 만들지 않아 NUL 종료와 충돌하지 않는다. 출력기는 인덱스를 L/V/T로 나눠 구성 글리프를 합성한다. 이 토큰식은 최종 달무리의 토큰 배정식과 다르다.

## 원본 함수와 연결

단일 문자 폭 조회는 `2326:0009`, 메뉴 폭 사전 계산에 쓰는 문자열 전체 폭 합산은 `2326:002F`다. 전체 폭 함수는 바이트 수를 반복 횟수로 쓰므로 한글 토큰 처리 시 문자열 포인터와 카운터에 두 바이트 소비를 함께 반영해야 한다. 실제 문자 출력은 `29C7:0004`가 담당한다. 정방향·역방향 폭 조회도 두 바이트 경계를 지켜야 하며, 문자열 포인터가 없는 단일 문자 폭 함수에서 호출자의 포인터를 임의로 변경하지 않는다.

비트맵의 조합 일치와 실제 화면 가독성은 별도 검사다. 구성 글리프 비교는 [완성 음절 대조](completed_syllable_fnt_test.md), 최종 글꼴은 [폰트 안내](../../FONTS.md)를 따른다.

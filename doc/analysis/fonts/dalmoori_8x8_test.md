# 달무리 8×8 완성 음절의 저장과 출력 셀

달무리는 초성·중성·종성 합성 대신 완성 음절의 8×8 비트맵을 읽는다. 필요한 음절을 모아 FNT에 저장하고 게임 문자열의 2바이트 토큰을 글리프 슬롯에 연결한다.

## 비트맵과 폭

글리프 비트맵은 8행이며 한 행이 1바이트다. 원본 잉크 크기를 바꾸지 않고 좌우 각 1픽셀 여백을 더한 10픽셀 셀을 사용한다. 기존 스타일의 문자 간격이 최종 전진 폭에 더해진다.

빌드는 등록 음절을 가나다순으로 정렬하고 완성 FNT와 토큰 대응표를 함께 만든다. FNT의 각 레코드는 물리 글리프 슬롯 2바이트와 비트맵 8바이트로 구성된다. 실제 토큰 범위는 [현재 폰트 규약](../../FONTS.md#2바이트-토큰과-출력-규약)을 따른다.

## 원본 인터페이스

폭 콜백과 문자열 판독은 역할이 다르다. 폰트 세그먼트를 전달받는 폭 콜백에서 문자열 후행 바이트를 읽지 않는다. 실제 문자열 포인터가 있는 경로에서만 토큰을 해석한다. 세부 계약은 [폭 콜백](dalmoori_width_contract.md)에 설명한다.

## 메모리

달무리 데이터는 MZ 상주 이미지에 포함한다. 별도 DOS 폰트 블록을 만들지 않으며 폰트 크기에 맞춰 치트 모듈·스택·재배치를 함께 계산한다. 치트 배경은 XMS를 사용한다. 파일 이름·화면 구간만으로 원본 폰트를 덮어쓰지 않고 문자열의 한글 포함 여부와 출력 문맥을 따른다.

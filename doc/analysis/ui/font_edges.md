# 원본 스타일을 따르는 글리프 가장자리

글리프의 테두리·그림자는 출력 호출의 스타일 색상표로 결정한다. 한글·달무리 영문·숫자·부호·단축키에 같은 규칙을 적용한다. 폰트 이름이나 화면 허용 목록으로 테두리 여부를 정하지 않는다.

## 픽셀 클래스

본체를 오른쪽·아래·오른쪽 아래로 1픽셀 이동한 영역에서 본체를 제외한 픽셀이 가장자리 2다. 가장자리 3은 나머지 8방향 주변 픽셀이며 우선순위는 본체→가장자리 2→가장자리 3이다. 이 분류는 원본 NEW6P의 94개 ASCII 글리프 4,311픽셀과 대조한 규칙이다.

| 스타일 | 가장자리 2 | 가장자리 3 | 표시 |
|---|---|---|---|
| 10h | 0 | 0 | 본체만 |
| 20h | 0Ch | 0 | 오른쪽·아래 그림자 |
| 30h | 0Ch | 0Ch | 양쪽 가장자리 |
| 40h | E8h | 0 | 별도 색 그림자 |

## 원본 호출과 비트맵 버퍼

`0EED:1E65`의 스타일 분기와 `1F27..1F63` 색 설정을 유지한다. 한글 출력기의 가장자리 판단 위치는 분석 모듈 `3D02:00A5`, 생성 루틴은 `026D`·`0294`다. 본체·테두리 분기는 모두 같은 작업 비트맵을 초기화해야 한다.

작업 버퍼가 `0449h`인 비교 구현에서 테두리 분기의 `DI`가 초기화되지 않으면 다른 메모리에 쓰고 빈 글리프를 출력한다. 두 분기 모두 `MOV DI,0449h` 이후 행 생성으로 들어가야 한다.

## 줄 간격과 검사

원본 `29C7:0004`는 활성 폰트 높이를 지역 변수에 저장하고 CR·자동 줄바꿈에서 `DS:[6CFA]`를 더한다. 8픽셀 본체에 10픽셀 테두리를 붙인 설명은 줄 피치 11이 필요하다. 첫 줄을 옮기거나 전역 폰트 높이를 바꾸는 대신 해당 출력 문맥의 높이를 계산한다.

검사는 본체 좌표, 가장자리 클래스, 네 스타일의 색과 원본 드라이버 출력을 함께 대조한다. 적용 호출과 정보창의 복원 계약은 [스타일·정보창 검사](menu_edge_test.md)를 따른다.

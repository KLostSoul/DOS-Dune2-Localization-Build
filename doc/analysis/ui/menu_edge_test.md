# 원본 스타일과 정보창 줄 간격의 검사 기준

한글 출력은 원본 포맷 함수의 스타일을 그대로 사용한다. 타이틀·게임 메뉴·도움말·임무 결과·명예의 전당은 각각 원래 호출의 색상표를 받으며 화면별로 테두리를 강제하지 않는다.

## 원본 스타일 보존

`0EED:1F27..1F63`의 원래 스타일 분기와 색 설정을 대조한다. 명예의 전당의 다섯 호출 `331B:0D75`, `1276`, `129A`, `12BD`, `13A3`은 원본 20h를 사용한다. 생산 퍼센트의 원래 가변 인자 출력도 유지한다.

가장자리의 픽셀 분류와 스타일 값은 [글리프 가장자리](font_edges.md)를 따른다. 한글뿐 아니라 괄호·단축키 대문자·숫자·부호에도 같은 검사 기준을 적용한다.

## 정보창의 지역 간격

유닛·건물 정보창 `0EED:0F1A` 안에서만 세로 간격 `DS:[6CFA]`를 1 증가시킨다. 함수 진입 때 원래 값을 스택에 저장하고 반환 전에 복원한다. 연속 0 초기화 22개를 동등한 짧은 명령으로 정리해 공간을 확보한다.

실제 `DUNE.ENG #84` 두 행의 Y는 84·93이다. 공통 폰트 높이, 첫 행·버튼 좌표와 다른 화면 간격은 바꾸지 않는다. 코드 크기·MZ 배치·재배치는 유지한다.

## 검사 항목

- NEW6P·NEW8P·NEW10P·STD3P·INTRO의 ASCII를 네 스타일로 출력해 원본 픽셀과 대조한다.
- 사용 한글과 달무리 영문·숫자·부호를 본체 위치·가장자리 클래스·색상별로 비교한다.
- 생산 퍼센트 0·1·25·50·99·100에서 원본 서식 결과·스택·레지스터를 검사한다.
- 정보창 간격의 입력값 -2·0·2에 대해 반환 시 간격·DI·SI·BP·SP와 지역 초기화 결과가 복원되는지 검사한다.

`python tools/check_final_build.py --only styles spacing latin`으로 실행한다. 제한 명령 검사는 게임 전체 플레이와 구분한다.

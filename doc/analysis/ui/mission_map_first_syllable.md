# 임무 지도 INI 파서의 고위 바이트 판정

REGION INI에 문자열이 정상 저장돼 있어도 첫 한글 음절이 사라질 수 있다. 원인은 문자 분류 인덱스의 부호 확장이다.

## 결함

INI 파서 `32FF:03C8`과 공백 제거 `32FF:07E2`는 바이트를 `CBW`로 확장한 뒤 `DS:[7749h+BX]`의 ctype 표를 읽는다. 80h 이상 값은 음수 인덱스가 되어 표 앞의 상태 메모리를 읽는다. E5h는 올바른 E5h 항목 대신 `DS:772E`를 참조한다. 해당 값의 공백 비트에 따라 토큰을 잘못 제거한다.

## 수정

`32FF:04D8`, `05F7`, `067F`, `0825`, `085A`에서 `CBW; MOV BX,AX`를 같은 길이의 `MOVZX BX,AL`로 바꾼다. 00h~FFh를 256항목 표 안에서 판정하며 값 앞부분 처리와 복사 뒤 앞뒤 공백 제거에 모두 적용한다.

변경 명령은 총 15바이트다. 문자열·출력 좌표·폰트·INI 형식·메모리 할당·재배치를 바꾸지 않는다.

## 검사

제한 x86 실행에서 표 앞 메모리의 공백 비트를 켜고 수정 전 누락과 수정 후 보존을 비교한다. 지도 번역 43문구, 앞뒤 고위 바이트 256경우와 ASCII 공백·탭 제거를 대조한다. 이 조건 모델은 특정 화면의 실제 메모리 덤프와 구분한다. 구현은 `tools/runtime_patches.py`의 `region_patch`·`region_verify`다.

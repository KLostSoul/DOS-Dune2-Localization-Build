## 2026-10-25 임무 선택 지도 첫 음절 누락 수정

사용자 캡처에서 `아트레이데스는 전략적 요충지들을 장악했다.`의 첫 음절 `아`가 사라졌다. 생성된 `SCENARIO.PAK/REGIONA.INI`의 `GROUP1/ENGTXT13`에는 첫 음절의 2바이트 토큰까지 들어 있었다. 출력 영역 폭이나 CSV 문장 길이가 직접 원인은 아니었다.

INI 파서 `32FF:03C8`와 공백 제거 함수 `32FF:07E2`가 문자 바이트를 `CBW`로 부호 확장한 뒤 `DS:[7749h+BX]`의 ctype 표를 조회했다. 80h 이상은 음수가 되어 256바이트 판정표 앞의 게임 상태 영역을 참조한다. 예를 들어 선행 E5h는 표의 E5h 항목 대신 `DS:772E`를 읽는다. 그 상태값의 공백 비트가 켜지면 한글 토큰을 공백으로 잘못 제거한다. 따라서 같은 문구라도 실행 상태와 토큰 재지정에 따라 누락 양상이 달라질 수 있다.

다섯 조회 지점 `32FF:04D8`, `05F7`, `067F`, `0825`, `085A`의 `CBW; MOV BX,AX`(3바이트)를 `MOVZX BX,AL`(3바이트)로 바꿨다. 00h~FFh 바이트가 실제 256항목 표 안에서 판정되며, ASCII 공백·탭 제거는 유지한다. 값 앞부분 처리와 복사 뒤 앞뒤 공백 제거를 모두 포함한다. 문자열·좌표·글자 폭·행 간격·INI 형식은 바꾸지 않는다. EXE 패치 자체는 같은 길이의 15바이트이며 별도 상주·DOS·XMS 할당 증가나 재배치 변경은 없다.

- 에디터 통합: `tools/translation_editor/region_ini_tokens.py`, `model.py`의 빌드 단계와 `runtime_features.verify()`에 연결.
- 생성본: `build/translation-editor-20261025-181054-993405`
- EXE SHA-256: `c25774340b01858d1efbb1208ea5e6ffa38f4ca8ea19dae6ec1240a5282c2bf9`
- 실행: 루트 `번역_수정본_실행.bat`
- 검사: `tools/checks/check_region_ini_tokens.py`, 생성본의 `region-ini-token-check.json`.

실제 생성된 REGIONA.INI와 원래 INI 파서·문자열 비교/복사 코드를 제한 x86 실행했다. FAR 포인터 정규화만 항등 스텁으로 대체했고, 공백 판정표 앞 두 상태 바이트를 공백 비트로 설정하여 수정 전 `아`가 빠지고 수정 후 전체 문장이 유지되는 것을 재현했다. 캡처 당시의 실제 상태 메모리를 읽은 결과는 아니다. 이어 지도 영어 언어 슬롯의 번역 문구 43개 모두에서 음수 인덱스 영역을 공백으로 설정해도 원본 값이 보존되는 것을 확인했다. 80h~FFh가 문자열 앞/뒤에 오는 256경우와 ASCII 공백·탭 제거도 통과했다. 2바이트 토큰·929개 리소스 행·명예의 전당 72경우 검사도 통과했다. 새 생성본의 게임 화면 확인은 아직 하지 않았다.

현재 CSV에는 739개 사용 음절이 있어 이번 자동 폰트 확장의 상주 증가 보고는 4,736바이트다. 이전 738음절 생성본과의 16바이트 차이는 자동 폰트 재구성 결과이며 INI 패치의 추가 메모리가 아니다. CSV 저장값은 생성 전후 해시가 동일하다.

## 원본 경로

원본 `REGION%c.INI` 문자열(DS:2B7F)을 참조하는 FBOV 모듈은 `3306`이다. 모듈의 원본 파일 시작은 `0x53A60`이며, 현재 파일에서는 MZ 증가분을 더한다. 설명 그리기 함수 `3306:0F16`은 설명 띠를 그린 뒤 `0F83`에서 옵션 `0012h`, X=64, Y=175를 설정하고 `0F9C`에서 공통 포맷 출력기 `0EED:1E65`를 호출한다.

스타일 `10h`의 원본 수평 간격은 -2이다. 해당 호출 옵션에 원본 폰트·스타일·정렬 마스크와 겹치지 않는 전용 비트 `8000h`를 추가해 `8012h`로 설정했다. 공통 포맷 출력기의 스타일 처리 뒤 `1F82`에서 기존 빈 확장 공간 `3D02:03E0`의 짧은 처리를 호출한다. 스타일 `10h`는 원래 간격 -2로 설정하고, 전용 비트가 있는 호출만 -1로 조정한다. 이어 원래의 문자열 포인터 검사 명령을 실행한다. 이후 다른 스타일 `10h` 호출에서도 -2를 다시 설정하므로 간격이 다른 화면으로 남지 않게 한다.

글자 전진 폭이 원래보다 1픽셀 늘어난다. 시작 X/Y, 글리프, 색 변환, 테두리 스타일과 원본 출력 순서는 유지한다. MZ 재배치 항목 하나를 추가하며 파일 길이, 상주 이미지 크기, 폰트 및 XMS 할당은 늘리지 않는다.

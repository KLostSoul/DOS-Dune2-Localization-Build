# 임무 지도 설명의 가로 간격

임무 선택 지도 하단 설명은 X=64, Y=175를 유지하고 문자 간격을 -1로 설정한다. 원본 간격 -2보다 문자 전진 폭이 1픽셀 늘어난다.

## 출력 경로

REGION%c.INI 이름은 DS:2B7F에 있으며 관련 FBOV 모듈은 `3306`이다. 원본 파일의 모듈 시작은 `0x53A60`이다. `3306:0F16`이 설명 띠를 그리고 `0F83`에서 옵션·좌표를 설정한 뒤 `0F9C`에서 `0EED:1E65`를 호출한다.

## 전용 간격 옵션

옵션 `0012h`에 전용 비트 `8000h`를 더해 `8012h`로 전달한다. 공통 포맷 출력기의 `1F82`에서 확장 처리 `3D02:03E0`을 호출한다. 스타일 10h의 기본 간격은 -2로 설정하고 전용 비트가 있을 때만 -1로 바꾼다. 이후 원래 문자열 포인터 검사를 실행한다.

다른 호출은 스타일 설정 단계에서 자기 간격을 다시 설정한다. 위치·색·글리프·테두리와 원본 출력 순서는 보존한다. 분석 구현은 MZ 재배치 하나를 사용하며 별도 메모리 할당은 없다.

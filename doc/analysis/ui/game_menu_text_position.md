# 게임 메뉴 선택문 Y 위치 — 2026-10-22

사용자 요청: 게임 메뉴 버튼 안의 글자가 위에 붙어 있으므로 각 선택문을 1픽셀 아래로 이동한다.

정상 확인된 기준 빌드 `dalmuri639-original-flow-stringstyle-outline`(EXE SHA-256 `a08aee96003b26e014beba5085f10336c50d4be6f7439e10fb56bf89b8c9d035`)는 보존했다. 수정 복사본은 `build/dalmuri639-menu-text-y1`이다. 현재 실행 배치는 루트 `듄2_한글테스트.bat`이다.

게임 창 버튼 출력 함수 `3208:8042`는 버튼의 위치와 크기로 프레임을 그린 후, `8115`에서 `AX=DI`(버튼 위쪽 Y), `8117`에서 `add ax,2`, `811A`에서 Y 인자를 스택에 넣는다. 그 좌표는 `8134`의 공통 포맷 출력 호출에 전달된다. 기존 실측 기록에도 `3208:8134`에서 게임 메뉴의 불러오기·저장·설정 항목이 출력됨이 확인돼 있다.

현재 EXE 파일 `0x55246`의 `05 02 00`을 `05 03 00`으로 바꿨다. 기준 EXE와 달라진 바이트는 `0x55247`의 `02 → 03` 한 바이트뿐이다. 버튼 문자열 전체의 Y가 1 증가하며, 같은 공통 출력 함수를 쓰는 게임 창 버튼의 다시 그리기에도 적용된다. 프레임·마우스 판정·행 간격·창 제목 위치는 바꾸지 않는다.

- 수정 EXE SHA-256: `04099859d3ab7eafa5b5a528b7c851e452ebf5c7a242cb2c35171c857091064d`.
- 재현 도구: `tools/patch_dalmuri639_game_menu_y.py`.
- 보고서: 수정 빌드의 `game-menu-y-build-report.json`.
- 기존 한글 글리프, 메뉴의 테두리 제외, 설명문·짧은 설명의 1픽셀 행간을 유지한다.
- 메뉴 글리프 639개, 메뉴 문구와 세 가문의 짧은 설명 128개/298줄에 대한 제한 CPU 검사를 수정본에서도 통과했다. 이 검사의 메뉴 픽셀 대조는 같은 입력 좌표에서 글리프가 기준판과 같은지를 확인하는 것이며, 버튼 호출부의 Y 이동은 의도한 변경이다.
- DOSBox-X와 게임은 실행하지 않았다. 메뉴 위치의 실제 화면 확인은 사용자 확인 전이다.

## 부호 추가판에서 1픽셀 추가 이동

사용자가 게임 메뉴 텍스트를 한 칸 더 내려 달라고 요청했다. 현재 실행 대상이던 672개 글리프 빌드 `dalmuri672-symbols`를 보존하고 `build/dalmuri672-symbols-menu-y2`에 복사했다.

`3208:8117`의 `add ax,3 → add ax,4` 한 바이트만 변경했다. 직전 빌드보다 Y+1, 원래 게임 위치보다 누적 Y+2다. 현재 EXE 파일에서 명령 위치는 `0x55486`, 실제 변경 바이트는 `0x55487`이다. 글리프·줄 간격·프레임·치트·메모리 배치는 그대로다.

- 기준 SHA-256: `3493f548bb1d8b0f3f201f08186bb95a86b341c9540f64a5cbb45a2e9f95e88b`.
- 수정 SHA-256: `e198c3e1257ea5033b773c07afaaf6eebed94b960ec7bb16420b494a55957db7`.
- 재현: `tools/patch_dalmuri672_menu_y2.py`.
- 보고서: 수정본의 `game-menu-y-build-report.json`.
- 기준 해시·명령 서명을 확인했고, EXE 전체에서 바뀐 위치가 해당 한 바이트뿐임을 대조했다. 게임은 실행하지 않았다.
- 루트 `듄2_한글테스트.bat`은 이 수정본을 실행한다.

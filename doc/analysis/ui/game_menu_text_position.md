# 게임 메뉴 버튼 텍스트의 Y좌표

게임 메뉴는 버튼 위쪽 Y에 4픽셀을 더해 텍스트를 출력한다. 원본의 2픽셀 가산보다 아래로 2픽셀 이동한 값이며 버튼 프레임·마우스 판정·행 간격·창 제목은 그대로다.

## 원본 호출

원본 모듈 `32F5:0F21`는 버튼 프레임을 그린다. `32F5:0FF4`에서 버튼 Y를 AX에 읽고 `32F5:0FF6`에서 오프셋을 더한 뒤 `32F5:0FF9`에서 출력 인자로 전달한다. `32F5:1013`가 공통 포맷 출력 호출이다.

수정은 `ADD AX,2`의 상수를 4로 바꾸는 방식이다. 원본 EXE의 명령 위치는 파일 `0x52B26`, 상수 바이트는 `0x52B27`이다. 빌더는 고정 파일 위치를 가정하지 않고 모듈·명령을 대조한다.

## 적용 범위

같은 버튼 출력 함수의 다시 그리기에도 같은 Y가 적용된다. 폰트 비트맵·치트·줄 간격·MZ 메모리 크기를 바꾸지 않는다. 화면별 최종 좌표는 [런타임 안내](../../RUNTIME.md#최종-화면-간격)를 따른다.

# 멘타트 목록 대주제 위 여백

## 2026-10-22 변경

요청: 멘타트 주제 목록의 ‘가문’, ‘건물’ 같은 대주제 위에 1픽셀 공백을 추가한다.

기준 빌드는 `build/dalmuri672-symbols-menu-y2`이며 그대로 보존한다. 적용 빌드는 `build/dalmuri672-mentat-heading-gap`이다. 루트 `듄2_한글테스트.bat`이 새 빌드를 실행한다.

## 원본 경로와 수정

- `3208:5208`은 멘타트 목록의 표시 레코드와 원본 위젯을 연결한다.
- `3208:52F0`의 원본 비교는 레코드 `+6`의 `30h`를 대주제로 판별한다. 대주제는 위젯 `+38h=30h`, 일반 항목은 `31h`로 구분한다.
- 원본 위젯 생성 `3208:5547`은 첫 행의 상대 Y를 8, 행 간격을 8로 설정한다. Y는 위젯 `+20h`이며 출력 및 마우스 좌표 계산에 사용된다.
- 목록 갱신의 `52C3..5357`을 같은 공간 안에서 정리하여 대주제마다 1픽셀을 누적하고, 각 행의 위젯 Y를 `8 + 표시행번호×8 + 현재 행까지의 대주제 수`로 설정한다.
- 스크롤 후에도 첫 표시행에서 누적값을 초기화한다. 대주제가 첫 행이면 그 앞에도 1픽셀을 둔다.
- 원본의 세 문자열 포인터, 대주제·일반 항목 구분, 선택 색, 들여쓰기, 위젯 출력 호출 및 목록 순서를 유지한다.
- 대주제 아래의 일반 항목들도 누적 여백만큼 함께 이동한다.

## 배치

기존 코드 공간 149바이트 중 133바이트를 사용하고 나머지는 NOP으로 채운다. 함수 지역 스택만 2바이트 늘린다. 실행 파일 길이, 상주 이미지, 폰트, XMS 할당은 늘리지 않는다. 직전 게임 메뉴 선택문의 아래 2픽셀 이동과 672글리프 폰트·치트 변경을 기준 빌드에서 유지한다.

빌드 SHA-256: `2636ef6cff99b8fcc2b32e84e3c88dd515e2959b348537c232a751fffdcfa18d`

게임은 실행하지 않았다. 실제 목록 표시와 스크롤 상태는 사용자 확인 전이다.

재현 도구: `tools/patch_dalmuri672_mentat_heading_gap.py`
보고서: `build/dalmuri672-mentat-heading-gap/mentat-heading-gap-report.json`

## 추가 요청: 한 칸 더 내림

대주제 위 여백을 1픽셀에서 2픽셀로 늘렸다. 각 대주제와 그 아래 항목의 위젯 Y에 누적하는 값을 2로 변경했다. 적용 빌드는 `build/dalmuri672-mentat-heading-gap2`이며 직전 빌드도 보존한다. 루트 실행 배치를 새 빌드로 연결했다.

코드는 기존 149바이트 공간 중 135바이트를 사용한다. 직전 빌드 대비 실행 파일 크기와 메모리 할당 증가는 없다. 게임은 실행하지 않았다.

재현 도구: `tools/patch_dalmuri672_mentat_heading_gap2.py`

## 추가 요청: 소주제 위 1픽셀

대주제의 위 여백 2픽셀을 유지하고 일반 항목(소주제)의 위에도 각각 1픽셀을 누적하도록 수정했다. 위젯 Y를 함께 이동하므로 출력과 마우스 선택 좌표는 같은 값을 사용한다.

적용 빌드는 `build/dalmuri672-mentat-item-gap`이며 직전 빌드는 보존한다. 루트 `듄2_한글테스트.bat`을 연결했다. 늘어난 행 간격에 맞춰 표시 행을 11개에서 9개로 줄였으며 페이지 이동, 아래 방향 선택 경계, 스크롤바 표시 행 수, 스크롤 끝 제한, 생성 위젯 수를 함께 조정했다. 창 크기와 글리프는 바꾸지 않았다.

수정 위치: `3208:52C3..5357`의 누적 여백과 `4BB0,4C02,4C20,539A,53A6,547F,548B,569B`의 행 수 관련 상수. 실행 파일 크기와 메모리 할당 증가는 없다. 게임 실행 확인은 하지 않았다.

SHA-256: `db4f3986e74fb5454532b387c6671a7512ace3cbceaee03a614ba6d2a19b24c6`

재현 도구: `tools/patch_dalmuri672_mentat_item_gap.py`

## 첫 행 ‘브리핑’ 위치 복구

앞선 수정의 기준 Y 계산이 잘못되었다. 원본 `5547`의 생성 루프는 ID 2를 Y=8에, ID 3을 Y=16에 생성한다. 실제 목록 갱신 `5297..52A3`은 ID 3부터 사용한다. 따라서 첫 표시 행의 원래 상대 Y는 16이다. 이전 수정은 생성 시작값 8을 첫 표시 행에 적용해, 대주제 여백 2를 더하더라도 첫 행을 원래보다 6픽셀 위에 배치했다.

`build/dalmuri672-mentat-anchor-fix`에서 기준 Y를 16으로 복구했다. 첫 표시 행에는 앞 여백을 누적하지 않고, 두 번째 행부터 대주제 2픽셀·소주제 1픽셀을 누적한다. 브리핑은 원래 Y=16이며, 다른 화면의 폰트나 창 위치를 변경하지 않았다. 기존 9개 표시 행과 스크롤 관련 변경은 유지한다. 원본과 직전 빌드는 보존한다.

코드 138바이트를 기존 149바이트 공간에 배치했다. 실행 파일 크기와 메모리 할당 증가는 없다. 게임은 실행하지 않았다.

SHA-256: `2d233fb21664fe5fa4ddbcb1cffdafb8ee19bf780bff661adb2f6add6d9600a5`

재현 도구: `tools/patch_dalmuri672_mentat_anchor_fix.py`

사용자가 현재 실행 배치의 대상인 `build/dalmuri672-mentat-anchor-fix`를 확인한 뒤 “문제 없이 출력된다.”고 보고했다. 이번 멘타트 목록의 브리핑 위치 복구 및 대주제·소주제 간격 수정은 정상 출력이 확인된 상태로 기록한다.

- 첫 행 ‘브리핑’: 원래 위치(상대 Y=16) 유지.
- 두 번째 표시 행부터: 대주제 위 2픽셀, 소주제 위 1픽셀 공백.
- 표시 행 수: 9개. 출력 위치와 선택 영역은 같은 위젯 Y를 사용한다.
- 확인 빌드 SHA-256: `2d233fb21664fe5fa4ddbcb1cffdafb8ee19bf780bff661adb2f6add6d9600a5`.
- 실행 파일: `build/dalmuri672-mentat-anchor-fix/source/VIRGIN/DUNE2/DUNE2.EXE`.
- 실행 배치: 루트 `듄2_한글테스트.bat`.

확인 근거는 사용자의 실제 실행 결과이며, 에이전트가 별도로 게임을 실행한 것은 아니다. 마우스·키보드·스크롤의 개별 동작 전체를 확인했다는 의미로 확대하지 않는다. 앞 절의 ‘게임 실행 확인 전’ 기록은 각 수정 당시의 상태이며, 현재 목록 출력 상태는 이 사용자 확인 결과를 따른다.

# 멘타트 목록의 기준점과 행 간격

첫 표시 행인 브리핑의 상대 Y는 16이다. 두 번째 행부터 대주제 앞에 2픽셀, 일반 항목 앞에 1픽셀을 누적한다. 출력과 선택 영역은 같은 위젯 Y를 사용한다.

## 레코드와 위젯

`32E3:0847`은 표시 레코드와 원본 위젯을 연결한다. `32E3:092F`은 레코드 +6의 `30h`로 대주제를 판별한다. 위젯 +38h는 대주제 `30h`, 일반 항목 `31h`이며 Y는 +20h다.

위젯 생성 `32E3:0B86`은 ID 2를 Y=8, ID 3을 Y=16에 만든다. 실제 갱신 `32E3:08D6..32E3:08E2`은 ID 3부터 사용한다. 생성 루프의 첫 Y=8을 첫 표시 행의 기준으로 쓰면 브리핑이 위로 이동한다.

## 표시·스크롤 규칙

`32E3:0902..32E3:0996`에서 첫 표시 행의 누적값을 초기화하고 두 번째 행부터 여백을 더한다. 스크롤 후에도 같은 규칙을 적용한다. 표시 행 수는 9개이며 페이지 이동·선택 경계·스크롤바·끝 제한·위젯 생성 수를 함께 맞춘다.

행 수 관련 분석 위치는 `32E3:01EF,32E3:0241,32E3:025F,32E3:09D9,32E3:09E5,32E3:0ABE,32E3:0ACA,32E3:0CDA`다. 코드 138바이트를 기존 149바이트 구간에 배치하고 지역 스택만 2바이트 늘린다. 실행 파일 크기와 DOS/XMS 할당은 늘리지 않는다.

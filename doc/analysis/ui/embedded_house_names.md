# 가문 식별자와 한글 표시 이름의 분리

원본 가문 이름은 화면 표시뿐 아니라 REGION·멘타트·시나리오 파일 이름 구성에도 사용된다. 영문 이름을 제자리에서 한글로 덮어쓰면 식별자가 바뀌고 문자열 슬롯 길이도 넘을 수 있다.

## 원본 표와 표시용 조회

`3342:37EC+가문ID×30`은 원본 이름 FAR 포인터를 담는다. 원본 영문 식별자는 보존하고 `import/strings/executable_house_names.csv`에서 한글 표시 이름과 오프셋 표를 생성한다.

분석 모듈의 표시 이름 조회 함수는 `3D02:03FE`이며 AX의 가문 ID를 받아 AX=세그먼트, DX=오프셋을 반환한다. 이름은 `00B3..00DF`와 `0154..0158`, 오프셋 표는 `0148..0153`의 기존 빈 공간을 사용한다.

## 출력 호출

유닛 문맥 메시지 `077B:1724`, `176A`, 건물 메시지 `156F:2648`, `2686`, 선택 설명 `1836:27E6`은 표시 이름 조회를 사용한다. 원래 `%s` 서식과 문자열 결합·출력 호출을 보존한다.

명예의 전당은 `331B:1322..1331`의 행 조합에서 같은 표시용 조회를 사용한다. 저장 레코드·내부 가문 ID·원본 식별자 형식은 바꾸지 않는다. 저장된 영문 이름 문자열 자체를 일괄 치환하는 패치가 아니다.

구현과 검사는 `tools/runtime_patches.py`의 가문 이름·명예의 전당 처리에 있다. 원본 파일 오프셋은 추출 EXE의 위치이며 실행 시 주소와 구분한다.

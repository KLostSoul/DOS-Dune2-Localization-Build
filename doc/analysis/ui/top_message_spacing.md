# 게임 상단 메시지의 가로 간격·Y 위치

## 2026-10-22 요청

유닛 선택 설명(예: ‘아트레이아스 병사.’)의 문자 가로 간격을 1픽셀 늘리고 텍스트를 아래로 1픽셀 내린다.

## 적용

기준 빌드 `build/dalmuri672-house-names`는 보존하고 `build/dalmuri672-message-spacing`을 만들었다. 루트 `듄2_한글테스트.bat`의 실행 대상을 새 빌드로 연결했다.

원본 상단 메시지 큐 출력은 `0EED:0AFC`, `0EED:0B20`에서 각각 `DS:3688`, `DS:3638` 메시지 버퍼를 공통 포맷 출력기에 전달한다. 두 출력은 유닛 선택 설명뿐 아니라 같은 상단 띠에 표시하는 게임 상태 메시지에도 공통으로 사용된다.

- 옵션 설정 `0EED:0ADE`, `0EED:0B02`: `0012h → 8012h`. 임무 선택 설명에서 이미 사용하는 전용 가로 간격 비트를 재사용하여 간격을 -2에서 -1로 바꾼다. 문자 전진 폭이 1픽셀 늘며 폰트·색상·스타일은 유지한다.
- Y 설정 `0EED:0AE9`: 2 → 3.
- Y 설정 `0EED:0B0D`: 13 → 14.
- 두 메시지의 기존 줄 피치는 유지하고 각각 아래로 1픽셀 이동한다. 배경 띠와 다른 화면 좌표는 수정하지 않는다.

실행 파일의 4바이트만 변경했다. 파일 길이·상주 이미지·XMS 할당 증가는 없다. 가문 한글 이름, 명예의 전당 테두리와 앞선 간격 변경을 유지한다.

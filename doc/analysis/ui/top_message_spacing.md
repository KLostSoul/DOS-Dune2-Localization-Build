# 게임 상단 메시지의 가로 간격과 Y좌표

상단 메시지는 문자 간격 -1, 두 행의 Y=3·14를 사용한다. 원본보다 가로 전진 폭과 Y가 각각 1픽셀 증가하며 두 행의 피치는 유지한다.

## 메시지 버퍼와 호출

`0EED:0AFC`와 `0EED:0B20`이 각각 `DS:3688`, `DS:3638`의 메시지를 공통 포맷 출력기에 전달한다. 유닛 선택 설명과 같은 상단 띠의 상태 메시지에 공통 적용된다.

| 위치 | 처리 |
|---|---|
| `0EED:0ADE`, `0EED:0B02` | 옵션 `0012h`를 `8012h`로 설정해 문자 간격 -1 선택 |
| `0EED:0AE9` | 첫 행 Y=3 |
| `0EED:0B0D` | 둘째 행 Y=14 |

전용 간격 비트는 [임무 지도 설명](mission_map_text_spacing.md)과 같은 처리다. 배경 띠·폰트·스타일·다른 화면 좌표와 DOS/XMS 할당은 바꾸지 않는다.

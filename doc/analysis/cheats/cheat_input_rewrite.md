# 치트 입력 소유권과 Enter 전달

치트창은 게임 위젯이 입력을 소유한 상태에서만 열린다. 화면의 VGA 모드만 검사하면 메뉴나 이름 입력도 같은 모드이므로 Enter를 가로챌 수 있다.

## 정상 게임 상태 판정

1. 정상 게임 루프의 `044B:0309`에서 원래 페이지 0 선택 호출을 후크한다. 원래 메모리 쓰기와 AX 반환값을 재현하고 정상 게임 도달 플래그를 설정한다. 호출자의 `POP CX`가 원래 스택 인자를 제거한다.
2. 키보드 후크는 정상 게임 플래그와 `DS:[38EC] != 0`을 확인한다.
3. 현재 GUI 위젯 목록 `DS:[1902:1904]`와 게임 목록 `DS:[3C1A:3C1C]`가 같은 널 아닌 FAR 포인터인지 검사한다.
4. 실제 승패 선택 분기 `1223:0328`에서 플래그를 해제한다.
5. 비허용 상태에서는 키 누름·해제를 원래 처리기로 전달하고 반복 방지 상태도 갱신한다.

원본 `044B:030F..0317`은 게임 위젯 FAR 포인터를 전달한다. GUI 오버레이의 `0081..00E1`은 목록을 비교하고 `00DA`, `00DD`에서 `DS:1904`, `DS:1902`를 갱신한다. 오버레이 스텁의 논리 주소와 페이로드 내부 오프셋은 구분해야 한다.

## 결과 평가와 상태 전환의 차이

`1223:02A9`는 `044B:03FD`에서 매 루프 호출된다. `1223:02B4..02E2`의 조건 검사와 조기 복귀 때문에 실제 승패 처리가 없어도 반환한다. 이 함수 입구에서 치트창을 닫으면 정상 게임 중에도 입력이 해제된다.

일반 위젯 조회 호출도 게임 중 계속 사용한다. 이 호출 전체를 비허용 상태로 취급하면 치트 입력 자체가 차단된다. 입력 허용 여부는 호출 존재가 아니라 위젯 소유자로 결정한다.

## 화면 처리와의 경계

입력 소유권 판정은 화면 픽셀을 쓰지 않는다. 배경 저장과 패널 유지의 실행 순서는 [모달 대기](cheat_modal_wait.md), 전장 복사의 영향은 [화면 갱신 경로](cheat_panel_redraw.md)에 설명한다.

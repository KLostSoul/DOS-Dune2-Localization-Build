# 게임 내 치트 입력과 명령 처리

게임 진행 중 Enter로 치트창을 열고, 명령을 입력한 뒤 Enter로 실행한다. 빈 입력의 Enter와 Esc는 창을 닫는다. 잘못된 명령을 제출하면 오류 상태를 표시하고 입력줄을 비운다.

## 명령

| 명령 | 동작 |
|---|---|
| CREDITS | 크레딧 10,000 증가 |
| WIN | 임무 승리 요청 |
| LOSE | 임무 패배 요청 |
| FASTBUILD | 내 가문의 건물·유닛 생산 속도 5배 켜기·끄기 |
| REVEAL | 현재 플레이어의 지도·미니맵 공개 |

FASTBUILD는 전환 결과를 `FASTBUILD ON` 또는 `FASTBUILD OFF`로 표시한다. 수리·업그레이드·재충전과 적 가문의 생산에는 적용하지 않는다. REVEAL은 현재 가문 ID를 원본 발견 함수에 전달한다.

## 입력 소유권

치트 입력은 정상 게임 루프와 게임 위젯이 입력을 소유하는 동안에만 허용한다. 타이틀 메뉴, 저장·불러오기, 이름 입력에서는 Enter를 원래 키 처리기로 넘긴다. 조건과 원본 주소는 [입력 소유권](cheat_input_rewrite.md)에 설명한다.

키보드 인터럽트는 입력 버퍼·열림 요청·다시 그릴 필요를 갱신한다. 화면 저장·그리기·복원과 XMS 호출은 정상 게임 루프에서 수행한다. 창을 표시하는 동안 전장 루프를 대기시키는 방식은 [모달 대기](cheat_modal_wait.md)를 따른다.

## 배치와 구현

기본 치트는 `import/asm/cheat/cheat-hook-build.asm`, 추가 명령은 `import/asm/cheat/cheat-extra.asm`에 있다. `tools/cheats.py`가 최종 폰트 모듈의 크기에 맞춰 치트 세그먼트·스택·MZ 재배치를 계산한다. 화면 백업은 4 KiB XMS를 사용하며 FASTBUILD와 REVEAL 때문에 별도 메모리를 할당하지 않는다.

원본의 매 프레임 결과 평가 함수 `1223:02A9`와 실제 승패 선택 분기 `1223:0328`은 역할이 다르다. 입력을 닫거나 상태를 해제하는 처리는 실제 상태 전환에 연결해야 한다.

## 검사

`python tools/check_final_build.py --only cheats`는 명령 판독, 입력 소유권, 원본 함수 인자, 생산 가속·지도 처리와 메모리 경계를 검사한다. 제한 명령 실행은 화면·사운드를 포함한 게임 전체 실행 검사와 구분한다.

# 치트창의 모달 대기와 화면 복원

치트창을 그린 뒤 전장 루프가 계속 진행되면 전장 변경 구역 복사가 패널을 덮는다. 패널을 매 프레임 지우고 다시 그리는 방식은 전장이 노출되는 구간을 만들어 깜박임을 일으킨다.

## 실행 순서

정상 게임 루프의 `044B:0309` 후크에서 원래 페이지 선택을 수행한 뒤 창 열림 요청을 처리한다.

1. 전장 갱신을 마친 표시 화면의 128×32 배경을 4 KiB XMS에 저장한다.
2. 저장에 실패하면 패널을 그리지 않고 입력 상태를 닫는다. XMS 성공 판정은 CF가 아니라 `AX=1`을 사용한다.
3. 패널을 한 번 그리고 입력 내용·상태가 바뀔 때만 다시 그린다.
4. `STI; HLT`로 인터럽트를 허용한 채 대기한다. 전장 갱신·복사 호출은 진행하지 않는다.
5. 창을 닫을 때 배경을 한 번 복원하고 원래 게임 루프를 재개한다.

하드웨어 타이머와 인터럽트 카운터는 대기 중에도 움직인다. 이 대기는 게임의 모든 시간 변수를 정지·복구하는 기능은 아니다.

## 인터럽트와 공유 상태

키보드 IRQ는 입력 버퍼와 열림·닫힘·재표시 플래그만 갱신한다. 화면·XMS 함수는 호출하지 않는다. 명령 검색 위치는 IRQ의 로컬 스택에 보관해 화면 출력 임시 포인터 `DRAW_TEXT_PTR`과 겹치지 않게 한다.

재표시 플래그는 그리기 전에 해제한다. 그리는 동안 새 키 입력이 도착하면 다시 설정된 요청이 다음 반복까지 남는다. 배경의 일부 행만 저장된 상태를 완료로 취급하지 않는다.

## 테두리 색

아래쪽·오른쪽 선은 팔레트 `EBh`를 사용한다. 원본 UI 그림자색으로 RGB는 `(85,85,121)`이다. `08h`는 `(170,0,0)` 계열의 빨강이므로 같은 용도로 사용할 수 없다.

## 검수 범위

분기 범위, SP/BP 복귀 계약, `HLT` 앞 `STI`, IRQ의 화면·XMS 호출 부재, 저장 성공 판정과 복원 순서를 검사한다. 입력 조건은 [Enter 소유권](cheat_input_rewrite.md), 상주·XMS 배치는 [메모리 규약](cheat_memory_layout.md)을 따른다.

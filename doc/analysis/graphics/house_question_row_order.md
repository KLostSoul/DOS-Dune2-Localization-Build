# 가문 가입 질문의 행 선택

`import/GFX/images/ENGLISH/MISC.ENG/frame_000.png`의 완성 질문은 위에서 아트레이데스·오르도스·하코넨 순서다. 게임 내부 ID 순서와 다르므로 복사할 행을 변환해야 한다.

| 가문 ID | 가문 | PNG 행 | source Y |
|---|---|---:|---:|
| 0 | 하코넨 | 2 | 48 |
| 1 | 아트레이데스 | 0 | 0 |
| 2 | 오르도스 | 1 | 24 |

영어 분기의 source Y는 `(가문ID+2)%3*24`다. `3314:1398..13E6` 구간에서 ID×24에 48을 더하고 `AAM 72`의 나머지와 `CBW`를 사용한다. SI·인자 스택·두 FAR 복사 호출의 위치를 보존한다.

FRE·GER는 원래 가문별 조각 좌표와 두 번의 복사를 유지한다. ENG/FRE/GER×세 가문의 9조합에서 복사 인자와 SP·SI 보존을 검사한다. 구현은 `tools/runtime_patches.py`, 그림 형식은 [CG 안내](../../GRAPHICS.md#가문-가입-질문)를 따른다.

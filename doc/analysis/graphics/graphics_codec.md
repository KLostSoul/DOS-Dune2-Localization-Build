# CG 추출·편집·재인코딩 구조

CG 도구는 원본 PAK에서 선택 리소스를 해제해 인덱스 PNG를 만들고, 편집 PNG를 같은 리소스 형식으로 인코딩한다. 변경한 멤버만 PAK에 병합하고 나머지 멤버는 보존한다.

## 입력과 기준 자료

원본 PAK는 `export/PAK/`, 원본 리소스·PNG·매니페스트는 `export/GFX/`, 편집할 PNG는 `import/GFX/images/`에 있다. 매니페스트는 PAK 멤버, 프레임, 크기, 팔레트와 투명색을 연결한다. 편집 PNG는 원본 기준 자료와 별도로 읽는다.

## 지원 형식

CPS의 LCW/Format 80과 프레임형 SHP를 처리한다. 언어별 `.ENG` 확장자만으로 형식을 판단하지 않으며 실제 헤더와 프레임 구조를 판독한다. CPS는 보통 320×200 인덱스 화면이고, 언어 UI의 작은 버튼은 SHP 프레임이다.

## 인코딩 제약

크기·프레임 번호·색 번호·투명색을 유지한다. 같은 RGB에 여러 색 번호가 있으면 RGB만으로 역변환할 수 없으므로 원래 인덱스 팔레트를 보존한다. SHP 투명색 0번은 검정 픽셀과 별개의 메타데이터다.

## 사용과 검사

`python tools/build_game.py`는 편집 CG를 다른 패치와 함께 반영한다. 개별 추출·인코딩은 `tools/edit_cg.py export`와 `encode`를 사용한다. 명령과 선택한 10리소스·44PNG는 [CG 안내](../../GRAPHICS.md)를 따른다.

검사는 해제→인코딩→재해제의 픽셀·팔레트·투명색 일치, 프레임 수, PAK의 비대상 멤버 보존을 대조한다. 형식 처리는 `tools/cg_codec.py`, 프로젝트 입출력은 `tools/edit_cg.py`, PAK 코덱은 `tools/resources.py`가 담당한다.

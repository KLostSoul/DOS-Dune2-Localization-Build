# HERALD.ENG의 팔레트 색 번호

HERALD.ENG는 같은 RGB를 가진 색 번호가 있을 수 있다. 원본 팔레트의 검정 0번과 12번을 편집기가 하나의 번호로 합치면 화면 RGB가 같아도 원본 인덱스를 결정할 수 없다. 편집본의 검정이 7번으로 합쳐진 분석 표본에서 이 문제가 발생했다.

## 원본 번호 보존

`import/GFX/images/ENGLISH/HERALD.ENG/frame_000.png`는 원본 인덱스 팔레트를 유지해 저장한다. 기존 픽셀은 원본 번호를 유지하고 새 배경 픽셀은 해당 배경색 번호를 명시해야 한다. 분석 표본의 새 검정 배경 341픽셀은 0번을 사용했다.

팔레트 복원 검사는 RGB 화면이 바뀌지 않았는지와 색 번호가 올바른지를 각각 대조한다. `load_pixels` 검사와 CPS 재인코딩·재디코딩에서 팔레트·인덱스 픽셀의 일치를 확인한다. RGB만 같은 것을 통과 기준으로 삼지 않는다.

# 완성 문장 세 줄로 저장하는 가문 질문

영어 모드의 가문 가입 질문은 MISC.ENG 그림의 완성 문장 한 줄을 복사한다. 공통 문장과 가문 이름을 서로 다른 조각으로 합치는 원본 구조를 한글 어순에 맞춘 방식이다.

## 그림 배치

CPS 전체는 320×200이며 한 줄은 312×24픽셀이다. 현재 편집 PNG의 위→아래 순서는 아트레이데스·오르도스·하코넨이다. 행 선택은 [게임 ID와 PNG 행 대응](house_question_row_order.md)을 따른다.

## 영어 전용 분기

`DS:[37AA]==0`인 ENG는 `(0,sourceY,0,0,39,24,2,0)`으로 한 줄을 복사하고 다른 복사는 폭·높이를 0으로 둔다. X·폭은 8픽셀 단위이므로 39는 312픽셀이다. 원본의 페이지 2→0 복사 함수를 사용한다.

FRE·GER는 공통 앞부분 `(0,0,0,0,26,24,2,0)`과 가문명 `(0,가문ID×24+24,26,0,13,24,2,0)`을 원래대로 복사한다. 두 FAR 호출 `3314:13B3`, `13DF`와 인자 스택·SI를 보존한다.

## 검사 범위

세 언어×세 가문의 9조합에서 좌표·폭·페이지·SP·SI를 검사한다. 비영어 여섯 조합은 원본 인자와 같아야 한다. PNG의 한글 문장과 게임 ID 대응도 함께 검사하며, 문자열 CSV와 폰트 토큰을 그림 복사에 사용하지 않는다.

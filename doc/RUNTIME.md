# 런타임 패치와 화면 표시

현재 최종 빌드에 적용된 입력·출력·화면 전환 규칙을 정리한다. 실행 대상, 산출물 해시, 사용자 실행 확인 범위는 [현재 상태](STATUS.md)에서 관리한다. 빌드 과정은 [빌드](BUILD.md), 글리프 생성과 메모리 배치는 [폰트](FONTS.md)를 따른다.

이 문서의 근거로 연결한 `analysis/` 문서는 원본 코드와 수정 원인을 확인한 **원본 분석 기록**이다. 과거 후보의 주소·해시가 포함되어 있어도 보관 문서나 현재 실행 안내로 분류하지 않는다.

## 원본 출력 구조 유지

한글 처리는 원본의 포맷 함수, 문자 출력 루프, 폭 계산, 위젯 입력과 메모리 규약에 연결한다. 원래 문자열 처리 과정을 대체하는 별도 출력 엔진을 사용하지 않는다. 멘타트 INFO의 최대 본문 길이는 번역 후 데이터에 맞춰 다시 계산한다. 긴 본문과 짧은 그림 설명도 각각 원래 출력 경로를 유지한다.

원본과 한글 출력의 대조 근거는 [원본 출력 구조](analysis/engine/original_dalmoori_output.md), [원본 경로를 유지한 재구성](analysis/engine/native_output_rebuild.md), [멘타트 INFO 길이](analysis/engine/mentat_info_length.md)에 있다.

## 치트 입력

게임 진행 중 **Enter**로 치트창을 열고, 명령을 입력한 뒤 Enter로 실행한다. 영문 대소문자는 구분하지 않는다.

| 명령 | 현재 동작 |
|---|---|
| `CREDITS` | 크레딧 10,000 증가 |
| `WIN` | 임무 승리 처리 |
| `LOSE` | 임무 패배 처리 |
| `FASTBUILD` | 내 가문의 건물·유닛 생산 속도 5배 전환. 다시 입력하면 해제 |
| `REVEAL` | 현재 플레이어의 임무 지도와 미니맵 공개 |

빈 입력에서 Enter를 누르면 치트창을 닫는다. 잘못된 명령을 제출하면 오류 상태를 표시하며 입력줄 전체를 비운다. 입력 중 개별 글자를 오타로 판정하여 지우는 방식은 아니다.

`FASTBUILD`는 `FASTBUILD ON` / `FASTBUILD OFF`로 상태를 알린다. 수리·업그레이드·재충전·적 가문의 생산에는 적용하지 않는다. `REVEAL`은 현재 플레이어의 가문 ID를 원본 발견 함수에 전달하므로 적 가문의 발견 상태까지 함께 공개하지 않는다. 임무 전환 때 추가 치트 상태를 정리한다.

타이틀, 저장·불러오기, 스코어 이름 입력 등에서는 Enter를 원래 게임 입력으로 전달한다. 치트창의 화면 백업은 XMS를 사용하며, 텍스트·테두리·화면 복원은 기존 모달 입력 경로를 따른다. 생산과 지도 공개도 원본 게임 함수를 사용한다.

구현은 [cheats.py](../tools/cheats.py), [기본 치트 ASM](../import/asm/cheat/cheat-hook-build.asm), [추가 치트 ASM](../import/asm/cheat/cheat-extra.asm)이다. 후크·재배치·스택과 입력 처리의 근거는 [치트 설계](analysis/cheats/cheat_input_design.md), [메모리 배치](analysis/cheats/cheat_memory_layout.md), [모달 대기](analysis/cheats/cheat_modal_wait.md), [화면 다시 그리기](analysis/cheats/cheat_panel_redraw.md)를 참조한다.

## 번역문과 원래 단축키

번역문에 단축키를 대문자 접미사로 표시한다. 예를 들어 `공격(A)`, `이동(M)`, `후퇴(R)`, `경계(G)`다. 접미사의 ASCII 문자 코드는 유지하고, 한글 번역 구간에서는 괄호 `(`·`)`와 영문 단축키 글자도 달무리 글리프로 표시한다. 공백은 기존 단어 간격을 유지한다. 이 글리프에도 해당 출력 호출의 원본 스타일을 적용한다.

원본의 첫 영문자 판독에 한글 첫 바이트를 넘기는 대신, 번역문 접미사에서 키를 찾아 원래 키 등록·위젯·명령 경로에 전달한다. 대소문자는 원래 변환 함수 `27DE:00DA`로 처리한다. 번역하지 않은 ASCII 문자열, 숫자·Esc·고정 키와 별도 취소 키는 원래 처리를 유지한다.

| 입력 경로 | 적용 내용 |
|---|---|
| 유닛 명령·공통 위젯 | 접미사 키를 원래 등록과 명령 실행에 연결 |
| 타이틀 메뉴 | 별도 목록 입력 경로 `32E9:0200`의 두 비교 호출도 같은 원본 키 변환에 연결하여 P·R·L·E·H 유지 |
| 생산 선택 | `BUILD THIS(B)`·`RESUME GAME(R)`의 원래 B·R 유지. 화면의 SHP 버튼 그림과 입력 등록용 문자열은 별개 |

단축키 등록 경로와 주소는 [번역 단축키 분석](analysis/ui/translated_shortcuts.md)에 기록되어 있다.

## 원본 스타일 테두리

한글·달무리 영문·숫자·부호·단축키는 해당 출력 호출의 원본 스타일 색상표를 따른다. 특정 화면이나 폰트 이름만으로 테두리를 강제하지 않는다.

| 원본 스타일 | 가장자리 2 / 3 | 표시 |
|---|---|---|
| `10h` | `0 / 0` | 테두리 없음 |
| `20h` | `0Ch / 0` | 오른쪽·아래 그림자 |
| `30h` | `0Ch / 0Ch` | 양쪽 가장자리 |
| `40h` | `E8h / 0` | 원본 별도 색 그림자 |

한글의 가장자리 2는 본체를 오른쪽·아래·오른쪽 아래로 1픽셀 옮긴 영역에서 본체를 제외한 부분이다. 가장자리 3은 나머지 8방향 주변 픽셀이며, 우선순위는 본체 → 가장자리 2 → 가장자리 3이다. 원본 `NEW6P`의 클래스 규칙을 따른다.

공통 포맷 함수 `0EED:1E65`의 원래 스타일 분기를 사용한다. 명예의 전당의 다섯 호출은 원본 `20h`를 사용한다. 타이틀·게임 메뉴·도움말·임무 결과 등도 원본 호출에 테두리가 있는 곳에 같은 규칙을 적용한다. 생산 퍼센트의 원래 가변 인자 포맷 호출도 유지한다.

구현은 [fonts.py](../tools/fonts.py)의 스타일 적용·검사 단계이며, 가장자리 클래스의 대조는 [폰트 가장자리 분석](analysis/ui/font_edges.md)에 있다.

## 최종 화면 간격

아래 값은 게임 내부 좌표의 픽셀 단위다.

| 구간 | 최종 적용 |
|---|---|
| 게임 메뉴 버튼 텍스트 | 원본 Y 가산 `2 → 4`, 아래로 2픽셀 |
| 멘타트 목록 첫 브리핑 | 원래 상대 `Y=16` 유지 |
| 멘타트 목록 두 번째 표시 행부터 | 대주제 위 2픽셀·일반 항목 위 1픽셀을 누적. 표시 9행. 출력과 선택 위젯의 좌표를 함께 적용 |
| 짧은 그림 설명 | 원래 설명 구조를 유지하며 행 사이 아래쪽 1픽셀 여백 |
| 임무 선택 지도 하단 | `X=64`, `Y=175` 유지. 문자 가로 간격 `-2 → -1` |
| 게임 상단 메시지 | 문자 가로 간격 `-2 → -1`. 두 행의 `Y=2·13 → 3·14` |
| 유닛·건물 정보창 | 해당 함수 안에서 세로 간격 `+1`, 반환 때 복원. 문자열 #84의 두 행 `Y=84·92 → 84·93` |
| CHOAM 주문서 | 각 품목 행 사이 아래쪽 1픽셀 추가. 품목명 아래 구분선도 아래로 1픽셀. 첫 행과 열 위치는 유지 |

정보창의 `84·92 → 84·93`은 **Y좌표**이며 문자열 #84를 #93으로 바꾼다는 뜻이 아니다.

주문서의 행 진행은 `3298:0646`에서 `8 → 9`다. 제목 `Y=48`과 첫 품목 `Y=57`은 유지하고, 구분선만 `Y=55 → 56`으로 내린다. 구현은 [fonts.py](../tools/fonts.py)와 [runtime_patches.py](../tools/runtime_patches.py)에 있다.

## 지도 문장과 표시용 가문 이름

임무 지도 문장의 첫 음절이 사라지던 원인은 문자열 누락이나 시작 X좌표가 아니라 REGION INI 파서의 문자 분류였다. 원본 `CBW`가 `80h` 이상 바이트를 부호 확장하여 ctype 표 앞 메모리를 읽었고, 그 값의 공백 비트에 따라 한글 토큰이 지워졌다.

원본 명령과 제한된 x86 재현·검수 범위는 [지도 첫 음절 누락 분석](analysis/ui/mission_map_first_syllable.md)에 있다.

`32FF:04D8`, `05F7`, `067F`, `0825`, `085A`의 명령을 같은 길이의 `MOVZX BX,AL`로 바꿔 256항목 표 안에서 판정한다. ASCII 공백 처리, 문장 길이와 출력 좌표는 유지하며 추가 메모리나 재배치가 필요하지 않다. 구현과 검사는 [runtime_patches.py](../tools/runtime_patches.py)의 `region_patch`·`region_verify`다.

명예의 전당은 행을 만드는 `331B:1322..1331`에서 원래 영문 이름 포인터 대신 기존 상주 표시용 가문 이름 조회 `3D02:03FE`를 사용한다. 번역값은 [executable_house_names.csv](../import/strings/executable_house_names.csv)에서 생성한다. 내부 가문 식별자·영문 이름과 명예의 전당 저장 레코드 형식은 유지한다. 구현은 같은 파일의 `hall_patch`·`hall_verify`, 원본 이름 참조 근거는 [내장 가문 이름 분석](analysis/ui/embedded_house_names.md)에 있다.

## 보안 질문 생략과 임무 전환

최종 전환 순서는 **정복 지도 페이드아웃 → 임무 설명 화면 준비 → 페이드인**이다. 보안 질문의 문구·CG·입력을 생략하되 원래 호출의 정리와 임무 설명 상태 처리는 유지한다.

| 위치 | 현재 처리 |
|---|---|
| `32DD:10AA` | 초기화 뒤 성공값 1을 설정하고 원래 공통 정리 지점 `16B8`로 연결 |
| 메인 루프의 EXE `0x9258`부터 12바이트 | 임무 설명 대기 상태 `DS:38B2=1`이면 그 회차의 팔레트 갱신 `044B:0559`를 건너뛰고 원래 상태 처리 진행 |
| `32DD:0BD8` | 첫 문구 대기 `ADD DX,1Eh`를 `ADD DX,0`으로 변경 |

지도 선택 호출자의 페이드아웃 뒤 공통 정리를 거쳐 설명 상태를 설정하고, 다음 메인 루프에서 원래 시나리오 로드·화면 준비·출력·페이드인으로 진행한다. 설명 준비 전에 옛 지도 팔레트가 복구되어 깨진 지도 화면이 드러나던 경로를 막고, 첫 문구 전 회색 패널 대기를 제거한다. 이후 문구의 원래 15틱 간격은 유지한다.

원래 프롤로그·정리·레지스터·`RETF` 규약을 보존한다. 위 EXE 파일 오프셋은 분석 대상의 위치이며 빌더는 대상 모듈을 찾아 패치 전후 바이트를 검사한다. 전체 호출 순서와 원인 근거는 [보안 질문과 임무 설명 전환 분석](analysis/engine/security_briefing_transition.md), 구현은 [runtime_patches.py](../tools/runtime_patches.py)에 있다.

## 영상 자막과 입 애니메이션

영어 모드에서도 자막과 음성을 함께 출력한다. 자막 전처리는 한글 2바이트 토큰을 한 쌍으로 보존하여, 토큰의 일부가 ASCII 제어문자처럼 처리되지 않게 한다. 오프닝·엔딩·황제 영상의 유니폰트 생성과 적재는 [폰트](FONTS.md)를 참조한다.

| 대상 | 현재 처리 |
|---|---|
| 하코넨 두 번째 황제 영상 | 마지막 `DUNE.ENG #320`을 위해 360틱 연장. 원래의 명목 18틱 프레임 간격에 맞춰 추가 구간에도 입 애니메이션 갱신 |
| 오르도스 두 번째 황제 영상 | 마지막 `DUNE.ENG #308`을 위해 360틱 연장. 원래의 명목 16틱 프레임 간격에 맞춰 추가 구간에도 입 애니메이션 갱신 |

각 가문의 해당 영상 분기에만 연결하며 다른 영상의 자막 표와 종료 동작을 바꾸지 않는다. 추가 시간에도 원래 WSA 갱신 경로를 실행한다. 실제 프레임 간격에는 원래와 같이 장면 준비 시간과 정수 나눗셈이 반영된다. 구현은 [scenes.py](../tools/scenes.py)와 [scene ASM](../import/asm/scene/)이다.

원본 참조와 패치 범위는 [영어 자막 분석](analysis/engine/english_subtitles.md), [하코넨 마지막 자막 분석](analysis/engine/harkonnen_final_caption.md), [오르도스 마지막 자막 분석](analysis/engine/ordos_final_caption.md)에 있다.

## 원본 영어 리소스의 언어 예외

원본 CD의 `ENGLISH.PAK/MENTATH.ENG`에는 독일어가 들어 있다. 원본 인덱스 #37의 본문은 `Die Elitetruppen des Imperators.`, #44의 이름은 `Frigatte`이며 같은 항목의 설명에도 독일어가 사용된다. 다른 언어 PAK를 잘못 추출한 결과가 아니다.

CSV의 `source_en`은 영어 리소스에서 읽은 원문이라는 뜻이며 모든 행이 영어라는 보장은 아니다. 번역의 원본 인덱스와 최종 Fix 리소스의 병합·재배열은 구분한다. 원문 대조 근거는 [영어 리소스 언어 분석](analysis/resources/english_resource_languages.md)에 있다.
